# 12-Week Linux Learning Programme

## How we will study

- Study 3–5 days per week, for 45–60 minutes per session.
- Each lesson follows: explain → demonstrate → practise → small challenge → notes.
- Use the Linux Mint VM for practical work. Ask before running unfamiliar commands that change system settings or files.
- At the end of each week, complete a review task and update GitHub and Notion.

## Phase 1 — Getting comfortable with Linux

### Week 1: First boot and desktop orientation
- Complete installation and confirm Linux Mint starts correctly.
- Learn the desktop, menus, settings, file manager, and terminal.
- Understand the difference between Windows and Linux.
- Outcome: open the terminal and find basic system information.

### Week 2: Terminal navigation and files
- Learn the current directory, home directory, paths, and hidden files.
- Practise `pwd`, `ls`, `cd`, `mkdir`, `touch`, and `cat`.
- Create and organise a practice folder.
- Outcome: manage a simple folder structure from the terminal.

### Week 3: Essential commands and help
- Learn `cp`, `mv`, `rm` (only in a safe practice folder), `less`, `head`, `tail`, `man`, and `--help`.
- Understand command options and arguments.
- Outcome: complete a file-management challenge and explain each command.

## Phase 2 — Understanding and managing the system

### Week 4: Users, groups, and permissions
- Learn users, groups, file ownership, and read/write/execute permissions.
- Understand `sudo` and why administrator access needs care.
- Practise reading permissions with `ls -l`.
- Outcome: explain who can access a file and why.

### Week 5: Software and package management
- Learn repositories and packages.
- Use the Software Manager and learn the purpose of `apt`.
- Understand updates and how to check before installing.
- Outcome: use Software Manager and understand equivalent package commands.

### Week 6: Processes and system monitoring
- Learn processes, CPU, memory, storage, and services.
- Explore System Monitor and commands such as `ps`, `top`, `free`, and `df`.
- Outcome: produce a short system information report.

## Phase 3 — Networking and automation

### Week 7: Networking foundations
- Learn IP addresses, routers, DNS, gateways, and ports.
- Explore `ip`, `ping`, and `getent`.
- Understand basic network troubleshooting.
- Outcome: write a report describing the VM's network connection.

### Week 8: Bash fundamentals
- Learn shell commands, variables, input/output, and simple scripts.
- Write a script that prints a welcome message and system date.
- Outcome: create and run your first Bash script.

### Week 9: Bash practice project
- Learn conditions, loops, and safe file handling.
- Build a simple dated study-log helper.
- Outcome: publish a documented Bash mini-project.

## Phase 4 — Development workflow and portfolio

### Week 10: Python on Linux
- Check Python availability and understand the interpreter.
- Create and run a basic Python file.
- Practise variables, input, conditions, and loops.
- Outcome: build a small command-line utility.

### Week 11: Git and GitHub from Linux
- Learn repositories, commits, branches, and README files.
- Configure Git identity locally; never publish private credentials.
- Practise tracking a project and publishing changes to this learning repository.
- Outcome: make a clean commit from the Linux VM.

### Week 12: Capstone and review
- Choose a small project combining Linux commands and a Bash or Python script.
- Document the goal, steps, screenshots if useful, and what you learned.
- Review the roadmap and choose the next focus: Linux administration, networking, or automation.
- Outcome: one finished project in the GitHub portfolio.

## First lesson — once the Linux desktop is ready

1. Start the Linux Mint VM and sign in.
2. Find the Terminal application from the menu.
3. Open it and run these read-only commands one at a time:

    whoami
    pwd
    ls
    uname -a

4. Write down what each command displays. Do not type commands you do not understand.
5. Tell me what you see, and we will work through the results together.
