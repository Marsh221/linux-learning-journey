# Linux Command Notebook

Record commands with a plain-language explanation and a safe example.

| Command | Purpose | Example | Notes |
|---|---|---|---|
| `pwd` | Show current directory | `pwd` | Read-only |
| `ls` | List directory contents | `ls -la` | Read-only |
| `whoami` | Show current username | `whoami` | Read-only |
| `uname` | Show system information | `uname -a` | Read-only |
| `man` | Open a command manual | `man ls` | Press `q` to exit |
