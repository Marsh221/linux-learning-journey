# Practice Exercises

Start with these beginner-friendly tasks inside the Linux Mint VM:

1. Open the terminal and run `pwd`.
2. List files with `ls -la`.
3. Move into your home directory with `cd ~`.
4. Create a practice folder with `mkdir linux-practice`.
5. Enter it and create a blank file with `touch first-note.txt`.
6. Confirm the file exists with `ls -l`.
7. Read the help for `cp` using `man cp`, then exit with `q`.

Write down what each command does. Avoid using `sudo` for these exercises.
