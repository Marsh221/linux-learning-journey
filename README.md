# Linux Learning Journey

A hands-on learning portfolio covering Linux fundamentals, system administration, networking, Bash scripting, Python, Git and practical automation.

## My learning environment

- **Host computer:** Dell Latitude 7390 (Windows 64-bit)
- **Virtualisation:** Oracle VirtualBox
- **Linux distribution:** Linux Mint XFCE 64-bit
- **Virtual machine storage:** External drive, in `F:\\Linux-VirtualMachines`
- **VM resources:** 3 GB RAM, 2 CPU cores, 40 GB dynamically allocated virtual disk

> Keep the external drive connected whenever the virtual machine is running. Shut down the VM before disconnecting it. Never select or format the physical external drive during Linux installation.

## Learning roadmap

1. Linux desktop, terminal and file-system navigation
2. Essential commands and command-line help
3. Files, folders, users and permissions
4. Software packages, updates and repositories
5. Processes, services and system monitoring
6. Networking fundamentals and troubleshooting
7. Bash scripting and task automation
8. Python on Linux
9. Git, GitHub and version control
10. Practical projects and a learning portfolio

## Session log

For each study session, record:
- Date and time
- What I learned
- Commands practised
- What worked
- What confused me
- Next step

## Learning principles

- Practise commands in the Linux Mint virtual machine.
- Understand a command before using it with administrator privileges.
- Do not run commands copied from the internet without understanding what they do.
- Keep notes of errors and how they were solved.
- Make small, regular commits to track progress.
